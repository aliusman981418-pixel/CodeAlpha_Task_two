Requirements#
A modern web browser
No installation, server, or build tools are required for basic use.
How to Run#
Download or clone this repository.
Open Rehan_Task two.html.html in a modern web browser.
Use the Back and Next buttons or the left/right arrow keys to navigate.
Try the interactive phishing-email exercise.
Complete the quiz and review your score and feedback.
If you rename the file to phishing_awareness.html, open that filename instead.

Technologies Used#
HTML5
CSS
JavaScript
Learning Objectives#
Recognize common phishing warning signs.
Understand how fake links and lookalike domains work.
Learn to verify unexpected requests through a separate trusted channel.
Practice safer password and multi-factor authentication habits.
Understand what to do after clicking a suspicious link or sharing credentials.
Safety Note#
This website is an educational awareness resource. If you suspect a real phishing incident, follow your organization's security procedures and report it to the appropriate support or security team.
